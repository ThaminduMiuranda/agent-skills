# Nicknames and fallback paths

Built-in fallback, baked into the plugin build. Discovery finds harness-comms projects on its own, and your own nicknames belong in
`check-comms-registry.md` on the linked computer (see `registry.md`, managed by add-project and remove-project). This list only adds
nicknames and paths for every install of a build.
